# Refinery 0.3.38
- The recording indicator responds to speech without growing as large.
- Optional screen context captures the display under the pointer at the start of recording. Refinery reads visible text on the Mac and sends only that text with the writing request; the image is not uploaded or saved.
- A screen context shortcut and recording menu action allow a one-off capture. Highlighted text is no longer collected as recording context. Selecting text to rewrite still works as before.
- Automatic update checks are on by default. You can turn them off in General settings; downloads and installation still ask you first.
Screen context requires macOS Screen Recording permission. You can enable it in Refinery Settings → Permissions. macOS may ask you to restart Refinery after granting it.

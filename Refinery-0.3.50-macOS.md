## Refinery 0.3.50

- Writing styles now have their own names and instructions. Create multiple custom styles, edit built-in styles, and reset a built-in style to its original instructions. Existing instructions are migrated into the new library, which also syncs through iCloud when enabled.
- Style and length work together. The default length applies to the selected style, while a menu change affects just one recording. App-specific settings can use any built-in or custom style.
- The Shortcuts page uses consistent row heights, separates recording from rewriting, and has shorter guidance.
